# Library Management System

A console-based Library Management System built in pure Java, demonstrating core OOP principles, collections, and file-based persistence — no frameworks.

## Features (planned)
- Add, search, and remove books
- Member registration and management
- Borrow/return workflow with due dates
- Data persistence via file I/O

## Tech Stack
- Java (no external frameworks)
- Collections API (HashMap, ArrayList)
- File I/O / Object Serialization
